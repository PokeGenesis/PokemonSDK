  <files>
    Directory.Build.props
  </files>
  <action>
    Créer `Directory.Build.props` à la racine du repo (même niveau que `PokemonSDK.slnx`) :

    ```xml
    <Project>

      <PropertyGroup>
        <!-- Identité package — partagée par tous les packages NuGet -->
        <Authors>PokeGenesis</Authors>
        <Copyright>Copyright © 2026 PokeGenesis</Copyright>
        <PackageLicenseExpression>MIT</PackageLicenseExpression>
        <PackageProjectUrl>https://github.com/PokeGenesis/PokemonSDK</PackageProjectUrl>
        <RepositoryUrl>https://github.com/PokeGenesis/PokemonSDK</RepositoryUrl>
        <RepositoryType>git</RepositoryType>
        <PackageReadmeFile>README.md</PackageReadmeFile>

        <!-- Par défaut : rien n'est packable.
             Les 7 projets SDK déclarent explicitement <IsPackable>true</IsPackable>. -->
        <IsPackable>false</IsPackable>
      </PropertyGroup>

      <!-- Bundler README.md (racine repo) dans chaque package NuGet -->
      <ItemGroup Condition="'$(IsPackable)' == 'true'">
        <None Include="$(MSBuildThisFileDirectory)README.md"
              Pack="true"
              PackagePath="\" />
      </ItemGroup>

    </Project>
    ```

    **Pourquoi `$(MSBuildThisFileDirectory)` :** pointe toujours vers le dossier contenant
    `Directory.Build.props` (racine repo), indépendamment du projet qui hérite — les projets
    dans `src/plugins/` (2 niveaux de profondeur) trouvent le README sans chemin relatif fragile.

    **Ne pas** ajouter `<LangVersion>` ici — chaque projet le gère déjà via `ImplicitUsings`.
    **Ne pas** ajouter `<TreatWarningsAsErrors>` — non configuré dans les projets existants,
    ne pas introduire de changement comportemental inattendu.
  </action>
  <verify>
    `dotnet build PokemonSDK.slnx` → Build succeeded, 0 erreurs.
    Aucun warning nouveau introduit par Directory.Build.props.
  </verify>
  <done>Directory.Build.props créé. IsPackable=false par défaut hérité par tous les projets. AC-1 satisfait.</done>
