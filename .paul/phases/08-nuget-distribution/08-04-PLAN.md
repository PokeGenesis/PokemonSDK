  <name>T1 : Build Release + pack 7 nupkg localement</name>
  <files>.gitignore</files>
  <action>
    1. Ajouter `nupkg-local/` à `.gitignore` si absent :
       ```bash
       grep -q 'nupkg-local' .gitignore || echo 'nupkg-local/' >> .gitignore
       ```

    2. Build Release avec SixLabors key extrait de sixlabors.lic :
       ```bash
       SIXLABORS_KEY=$(grep '^key=' src/SDK.Tools/sixlabors.lic | cut -d'=' -f2-)
       dotnet build PokemonSDK.slnx \
         --configuration Release \
         -p:SixLaborsLicenseKey="$SIXLABORS_KEY"
       ```
       Prérequis : `sixlabors.lic` présent dans `src/SDK.Tools/` (installé en Plan 08-02).
       Si déjà buildé en Release dans la session, le build est incrémental (rapide).

    3. Pack la solution (IsPackable=true sur 7 projets uniquement) :
       ```bash
       dotnet pack PokemonSDK.slnx \
         --configuration Release \
         --no-build \
         -o ./nupkg-local
       ```

    4. Vérifier le compte :
       ```bash
       ls ./nupkg-local/*.nupkg | wc -l   # doit retourner 7
       ls ./nupkg-local/                   # affiche les 7 nupkg nommés
       ```
  </action>
  <verify>`ls ./nupkg-local/*.nupkg | wc -l` == 7 ; les 7 fichiers sont PokeForge.SDK.*.0.1.0.nupkg</verify>
  <done>AC-1 satisfait : 7 nupkg présents dans ./nupkg-local/</done>

    ```xml
    <Project Sdk="Microsoft.NET.Sdk">
      <PropertyGroup>
        <TargetFramework>net10.0</TargetFramework>
        <IsPackable>false</IsPackable>
        <Nullable>enable</Nullable>
        <ImplicitUsings>enable</ImplicitUsings>
      </PropertyGroup>
      <ItemGroup>
        <PackageReference Include="PokeForge.SDK.Core"               Version="0.1.0" />
        <PackageReference Include="PokeForge.SDK.Data"               Version="0.1.0" />
        <PackageReference Include="PokeForge.SDK.Battle"             Version="0.1.0" />
        <PackageReference Include="PokeForge.SDK.Scripting"          Version="0.1.0" />
        <PackageReference Include="PokeForge.SDK.Plugins.Nuzlocke"   Version="0.1.0" />
        <PackageReference Include="PokeForge.SDK.Plugins.Randomizer" Version="0.1.0" />
        <PackageReference Include="PokeForge.SDK.Plugins.Turbo"      Version="0.1.0" />
        <PackageReference Include="xunit"                            Version="2.9.3" />
        <PackageReference Include="xunit.runner.visualstudio"        Version="2.8.2">
          <PrivateAssets>all</PrivateAssets>
        </PackageReference>
        <PackageReference Include="Microsoft.NET.Test.Sdk"           Version="17.12.0" />
      </ItemGroup>
    </Project>
    ```

    **SmokeTests.cs** — typeof() compile-time resolution prouve que chaque package est bien
    référencé et que ses types publics sont accessibles depuis un consumer NuGet :
    ```csharp
    using Xunit;

    namespace NuGetConsumerSmokeTest;

    public class PackagePresenceTests
    {
        [Fact]
        public void SDK_Core_resolves() =>
            Assert.NotNull(typeof(SDK.Core.Entities.PokemonSpecies));

        [Fact]
        public void SDK_Data_resolves() =>
            Assert.NotNull(typeof(SDK.Data.PokemonDbContext));

        [Fact]
        public void SDK_Battle_resolves() =>
            Assert.NotNull(typeof(SDK.Battle.BattleEngine));

        [Fact]
        public void SDK_Scripting_resolves() =>
            Assert.NotNull(typeof(SDK.Scripting.GameState));

        [Fact]
        public void SDK_Plugins_Nuzlocke_resolves() =>
            Assert.NotNull(typeof(SDK.Plugins.Nuzlocke.NuzlockePlugin));

        [Fact]
        public void SDK_Plugins_Randomizer_resolves() =>
            Assert.NotNull(typeof(SDK.Plugins.Randomizer.RandomizerPlugin));

        [Fact]
        public void SDK_Plugins_Turbo_resolves() =>
            Assert.NotNull(typeof(SDK.Plugins.Turbo.TurboPlugin));
    }
    ```

    Note : si un `typeof()` ne compile pas, ajuster le namespace dans SmokeTests.cs

    `dotnet tool run ilspycmd ./nupkg-local/PokeForge.SDK.*.nupkg` ou en ouvrant
    le nupkg (zip) → lib/net10.0/*.dll et inspectant les types publics.
