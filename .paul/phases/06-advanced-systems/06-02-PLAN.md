<acceptance_criteria>

## AC-1: FakemonAssembler alpha-composite N couches
```gherkin
Given N PNG de parties (1, 3, ou 5 couches) avec ZOrder défini
When FakemonAssembler.Assemble(layers) est appelé
Then retourne un Image<Rgba32> dont les pixels sont l'alpha-composite correct des couches dans l'ordre ZOrder croissant
  Et les couches de même ZOrder sont triées de façon stable (ordre d'apparition)
```

## AC-2: FakemonAssemblyPipeline erreur partie manquante
```gherkin
Given un FakemonAssemblyOptions avec un layer dont le path PNG n'existe pas
When FakemonAssemblyPipeline.Run() est appelé
Then FakemonAssemblyException est levée avec le path manquant dans le message
```

## AC-3: FakemonFilter applique les critères
```gherkin
Given un catalog de parties PNG avec métadonnées JSON (type, gen, egg-group)
When FakemonFilter.Apply(catalog, filter: "type:fire,gen:1") est appelé
Then retourne uniquement les parties dont les métadonnées correspondent au filtre
  Et les parties sans métadonnées sont incluses (compatibles avec tout)
  Et si résultat = 0 parties, retourne liste vide (l'appelant décide d'avorter)
```

## AC-4: FakemonExporter écrit PNG + insère fakemon_species
```gherkin
Given une Image<Rgba32> + options (identifier, generation, type1, translations)
When FakemonExporter.Export() est appelé
Then PNG écrit dans output dir (chemin calculé par convention fk_{identifier}_{view}.png)
  Et row fakemon_species insérée dans SQLite
  Et 6 translations insérées EntityType="FakemonSpecies" (D-22 si translations fournies)
```

    **FakemonPartLayer.cs** :
    ```csharp
    public record FakemonPartLayer(string Path, int ZOrder, string? BlendMode = null);
    ```
    Métadonnées optionnelles dans fichier sidecar JSON même nom que PNG : `fk_part_identifier.json` → `{"type":"fire","gen":1,"egg-group":"field"}`.

    **FakemonPartsCatalog.cs** :
    - `public static IReadOnlyList<FakemonPartLayer> Scan(string directory)`
    - `Directory.EnumerateFiles(directory, "*.png", SearchOption.AllDirectories)`
    - Limite à 500 PNG — au-delà : `Console.WriteLine("[WARN] catalog scan dépasse 500 PNG, tronqué")`, puis tronquer.
    - Pour chaque PNG : chercher sidecar `{basename}.json` → parser ZOrder depuis JSON si présent, sinon ZOrder=0.
    - Sidecar format : `{"type":"fire","gen":1,"egg-group":"field","z-order":3}` — tous optionnels.
    - Stocker métadonnées dans dictionnaire interne `Dictionary<string, JsonDocument>` pour FakemonFilter.
    - Méthode `GetMetadata(path)` retourne JsonDocument? pour le filtre.

    **FakemonFilter.cs** :
    - `public static IReadOnlyList<FakemonPartLayer> Apply(IReadOnlyList<FakemonPartLayer> catalog, FakemonPartsCatalog catalogInstance, string? filterExpression)`
    - Si filterExpression null → retourner catalog complet.
    - Parser filterExpression : `"type:fire,gen:1,egg-group:field"` → dict `{type:fire, gen:1, egg-group:field}`.
    - Pour chaque layer : charger sidecar via catalogInstance. Si pas de sidecar → inclure (compatible tout).
    - Si sidecar présent : vérifier chaque critère du filtre. Si toutes conditions OK → inclure.
    - Retourner liste filtrée (peut être vide — l'appelant gère l'erreur).

    **FakemonAssembler.cs** :
    - `public static Image<Rgba32> Assemble(IReadOnlyList<FakemonPartLayer> layers)`
    - Si `layers` vide → throw `FakemonAssemblyException("Aucune couche à assembler")`
    - Pour chaque layer : `Image.Load<Rgba32>(layer.Path)` — si fichier absent → throw `FakemonAssemblyException($"Partie manquante : {layer.Path}")`
    - Trier par ZOrder croissant (sort stable — `OrderBy` LINQ est stable en .NET).
    - Déterminer dimensions output = max(width, height) de toutes les couches (composition en carré).
    - Créer `new Image<Rgba32>(width, height)` transparent.
    - Pour chaque couche triée : `outputImage.Mutate(ctx => ctx.DrawImage(layerImg, new Point(0,0), 1f))`
    - Retourner image composite.
    - Éviter : ne pas utiliser `PixelAccessor` direct — utiliser `DrawImage` de ImageSharp (plus simple, gère alpha).

    **FakemonExporter.cs** :
    - `public static async Task ExportAsync(Image<Rgba32> image, FakemonAssemblyOptions opts, PokemonDbContext ctx)`
    - Calculer chemin output : `Path.Combine(opts.OutputDirectory, $"fk_{opts.Identifier}_front.png")`
    - `Directory.CreateDirectory(opts.OutputDirectory)` si absent.
    - `await image.SaveAsPngAsync(outputPath)` via ImageSharp.
    - Guard : si `ctx.FakemonSpecies.Any(f => f.Identifier == opts.Identifier)` → throw `FakemonAssemblyException($"Fakemon '{opts.Identifier}' existe déjà en DB")`.
    - Créer `FakemonSpecies` entity depuis opts → `ctx.FakemonSpecies.Add(entity); await ctx.SaveChangesAsync()`.
    - Si `opts.TranslationsJsonPath` présent : lire JSON (format: `{"en":"Name EN","fr":"Nom FR",...}`) → insérer 6 translations D-22 dans `ctx.Translations`. Fallback si clé absente : utiliser identifier.
    - Si `opts.TranslationsJsonPath` null : insérer 6 translations avec fallback = identifier pour toutes locales.

    **FakemonAssemblyPipeline.cs** :
    - `public static async Task<string> RunAsync(FakemonAssemblyOptions opts, PokemonDbContext ctx)`
    - Étape 1 : `FakemonPartsCatalog.Scan(opts.PartsDirectory)` → catalog.
    - Étape 2 : `FakemonFilter.Apply(catalog, catalogInstance, opts.FilterExpression)` → filtered.
    - Si filtered.Count == 0 : message `[WARN] Aucune partie compatible avec le filtre`. Si `opts.Strict` → throw `FakemonAssemblyException("0 parties après filtre, --strict activé")`. Sinon → return (no-op).
    - Étape 3 : `FakemonAssembler.Assemble(filtered)` → image.
    - Étape 4 : `await FakemonExporter.ExportAsync(image, opts, ctx)`.
    - Retourner chemin du PNG créé.
