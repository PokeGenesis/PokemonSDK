## AC-1: list-parts liste les parties disponibles
```gherkin
Given un répertoire --parts-dir avec des PNG de parties
When pokeforge fakemon list-parts --parts-dir <dir> [--filter type:fire]
Then affiche la liste des PNG compatibles avec le filtre (ou tous si pas de filtre)
  Et exit code 0
```

## AC-2: assemble crée un Fakemon
```gherkin
Given un répertoire --parts-dir avec des PNG + une DB SQLite --db-path
When pokeforge fakemon assemble --name blaziken-eagle --output assets/sprites/fakemons --parts-dir parts/ --db-path db.sqlite
Then PNG créé : assets/sprites/fakemons/fk_blaziken-eagle_front.png
  Et row fakemon_species insérée en DB
  Et exit code 0
```

```gherkin
Given un répertoire --parts-dir vide (0 PNG)
When pokeforge fakemon assemble --name test --parts-dir empty/ --strict

  Et exit code 1
```

  <files>
    src/SDK.Cli/Commands/FakemonCommand.cs,

  </files>
  <action>
    **FakemonCommand.cs** : Commande parent `fakemon` avec 2 sous-commandes.
    Pattern : même structure que `DoctorCommand.cs` (méthode `Register(RootCommand)` statique, `Execute` interne).

    ```
    pokeforge fakemon list-parts
      --parts-dir  (string, default "assets/parts")
      --filter     (string?, null par défaut)

    pokeforge fakemon assemble
      --name            (string, requis)
      --output          (string, default "assets/sprites/fakemons")
      --parts-dir       (string, default "assets/parts")
      --db-path         (string, default "src/SDK.Data/data/PokemonSDK.db")
      --filter          (string?, null)
      --translations-json (string?, null)
      --generation      (int, default 1)
      --type1           (int, default 1)  — id dans PokemonTypes
      --egg-group1      (string, default "field")
      --strict          (bool, default false)
    ```

    **list-parts Execute** :
    - `FakemonPartsCatalog.Scan(partsDir)` → catalog.
    - `FakemonFilter.Apply(catalog, catalogInstance, filter)` → filtered.
    - Afficher chaque entry : `[OK] {Path} (ZOrder={ZOrder})`.
    - Si 0 résultats : `[INFO] Aucune partie compatible`. Exit 0 (pas d'erreur sur list).

    **assemble Execute** :
    - Construire `FakemonAssemblyOptions` depuis les arguments CLI.
    - Créer `PokemonDbContext` via SqliteDbContextFactory (même pattern que SeedCommand).
    - Appeler `await FakemonAssemblyPipeline.RunAsync(opts, ctx)`.
    - Sur succès : `[OK] Fakemon '{name}' créé : {outputPath}`. Exit 0.
    - Sur `FakemonAssemblyException` : `[ERROR] {ex.Message}`. Exit 1.
    - Sur autre exception : `[ERROR] Erreur inattendue : {ex.Message}`. Exit 1.

    **Program.cs** : Ajouter `FakemonCommand.Register(rootCommand);` après `DoctorCommand.Register(rootCommand);`.
  </action>
  <verify>
    dotnet build src/SDK.Cli/SDK.Cli.csproj --configuration Release → 0 erreur.
    dotnet run --project src/SDK.Cli -- fakemon --help → affiche list-parts et assemble.
  </verify>
  <done>AC-1 + AC-2 implémentés — sous-commandes enregistrées.</done>
</task>
