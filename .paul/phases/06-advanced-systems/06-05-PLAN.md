## AC-1: Lua sdk.tts.* délègue au C# INarrationPlugin
```gherkin
Given un INarrationPlugin mock enregistré dans NpcInteractionRunner
When script Lua exécute : sdk.tts.speak("Attention !")
Then INarrationPlugin.Enqueue("Attention !") est appelé exactement 1 fois
  Et sdk.tts.stop() appelle INarrationPlugin.Stop()
  Et sdk.tts.is_speaking() retourne INarrationPlugin.IsSpeaking
```

## AC-2: Lua ne peut pas lancer de process
```gherkin
Given MoonSharp Preset_SoftSandbox actif
When script Lua tente : os.execute("piper ...") ou io.popen("aplay")
Then ScriptRuntimeException levée (SoftSandbox bloque os + io)
  Et INarrationPlugin.Enqueue() jamais appelé
```

## AC-3: pokeforge doctor vérifie piper + aplay
```gherkin
Given piper absent du PATH
When pokeforge doctor exécuté
Then affiche : "[WARN] piper TTS absent — pokeforge fakemon assemble TTS non disponible"
  Et affiche instructions d'installation
  Et exit code reste 0 (WARN non-bloquant)
```

    namespace SDK.Scripting.Bindings;
    using SDK.Core.Interfaces;

    public class TtsApi
    {
        private readonly INarrationPlugin _plugin;
        public TtsApi(INarrationPlugin plugin) => _plugin = plugin;

        public void Speak(string text) => _plugin.Enqueue(text);
        public void Stop() => _plugin.Stop();
        public bool IsSpeaking => _plugin.IsSpeaking;
    }

    **NpcInteractionRunner.cs** — Ajouter surcharge avec TTS :
    - Méthode statique existante : `Run(GameState state, string script)` — ne pas modifier.
    - Ajouter surcharge : `Run(GameState state, string script, INarrationPlugin? tts = null)`
    - Dans la surcharge : si `tts != null`, créer `TtsApi`, enregistrer dans MoonSharp :
      ```csharp
      UserData.RegisterType<TtsApi>();
      script.Globals["sdk"] = new { tts = new TtsApi(tts) };
      // ou via Table MoonSharp si le pattern existant l'exige
      ```
    - Vérifier le pattern existant de `BadgeApi` dans NpcInteractionRunner pour comprendre
      comment les globals sont enregistrés. Suivre exactement le même pattern.
    - Si `tts == null` : ne pas enregistrer `sdk.tts` (éviter null ref dans Lua).
    - Nota bene : MoonSharp SoftSandbox ne permet pas d'appeler Process.Start depuis Lua.
      L'appel `sdk.tts.speak()` → C# `TtsApi.Speak()` → `INarrationPlugin.Enqueue()` — safe.

    **DoctorCommand.cs** — Ajouter checks TTS à la fin de `Execute(configPath)` :
    - Vérifier piper : `IsCommandAvailable("piper")` (helper existant ou nouveau).
      Si absent : `[WARN] piper TTS absent — installez piper depuis https://github.com/rhasspy/piper`. Warning = hasError reste false.
    - Vérifier aplay : `IsCommandAvailable("aplay")` sur Linux. Sur Windows : skip ce check (aplay inutile).
      Si Linux + absent : `[WARN] aplay absent — TTS audio silencieux`.
    - Helper `IsCommandAvailable(string cmd)` : `Process.Start(new ProcessStartInfo("which", cmd) { RedirectStandardOutput=true })?.WaitForExit(); return exitCode == 0`. Sur Windows : utiliser `where` au lieu de `which`.
    - Les WARNs ne doivent pas incrémenter `hasError` (exit code reste 0).
