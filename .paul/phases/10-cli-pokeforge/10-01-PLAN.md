<objective>
## Goal
Créer le projet SDK.Cli (dotnet global tool `pokeforge`) avec la commande `new` : extrait StarterGame depuis un zip embarqué, renomme `StarterGame` → PascalCase(name) dans tous les fichiers texte, écrit le projet dans `<name>/`.

## AC-1: Commande `new` crée le projet
```gherkin
Given  aucun dossier `mon-jeu/` n'existe dans le répertoire courant
When   `pokeforge new mon-jeu` est exécuté
Then   un dossier `mon-jeu/` est créé contenant `MonJeu.csproj`, `Game1.cs`, `Program.cs`, `nuget.config`
       et le contenu de ces fichiers texte ne contient plus `StarterGame` (remplacé par `MonJeu`)
       et le code de sortie est 0
```

## AC-2: Conversion PascalCase correcte
```gherkin
Given  un nom en kebab-case `mon-jeu`
When   NewCommand convertit en PascalCase
Then   le résultat est `MonJeu` (split sur `-`, majuscule première lettre de chaque segment)
       et `single` → `Single`, `my-pokemon-game` → `MyPokemonGame`
```

## AC-3: Erreur si dossier existant
```gherkin
Given  un dossier `mon-jeu/` existe déjà dans le répertoire courant

Then   le code de sortie est 1
       et le message "Directory 'mon-jeu' already exists." est affiché sur stderr
       et aucun fichier n'est créé ou modifié
```

## AC-4: --help fonctionnel
```gherkin
Given  aucun argument ou `--help`
When   `pokeforge --help` ou `pokeforge new --help` est exécuté
Then   usage + description affichés, code de sortie 0
```

## AC-5: Fichiers binaires copiés sans modification
```gherkin
Given  le template contient des fichiers binaires (*.png, *.ogg, *.ttf)

       et les octets sont identiques aux fichiers source (aucun replace sur binaires)
```

<task type="auto">
  <name>Task 2: Implémenter NewCommand — extraction + rename</name>
  <files>src/SDK.Cli/Commands/NewCommand.cs</files>
  <action>
    Implémenter le corps de `NewCommand.cs`.

    **ToPascalCase(string name) :**
    - Split sur `-`
    - Chaque segment : `char.ToUpperInvariant(w[0]) + w.Substring(1)`
    - Join sans séparateur
    - Exemples : `mon-jeu` → `MonJeu`, `single` → `Single`, `my-pokemon-game` → `MyPokemonGame`
    - Ne pas split sur `_` (non spécifié dans le design)

    **Execute(string name) → int (exit code) :**
    1. Vérifier si `name/` existe → écrire sur stderr + return 1
    2. Lire le zip embarqué :
       ```csharp
       using var stream = Assembly.GetExecutingAssembly()
           .GetManifestResourceStream("starter-template.zip")!;
       ```
    3. Ouvrir `ZipArchive(stream, ZipArchiveMode.Read)`
    4. Pour chaque `ZipArchiveEntry` :
       - Calculer `destPath = Path.Combine(name, entry.FullName)`
       - Créer dossier parent si nécessaire
       - Si entrée dossier (entry.FullName se termine par `/`) : `Directory.CreateDirectory`; passer à la suite
       - Déterminer si fichier texte par extension :
         `new[] { ".cs", ".csproj", ".json", ".md" }` + `nuget.config` (sans extension)
       - `Content.mgcb` : traiter comme texte pour cohérence (le replace ne cassera rien)
       - **Fichier texte :** lire comme string UTF-8, remplacer `StarterGame` → pascalName, écrire
       - **Fichier binaire (*.png, *.ogg, *.ttf, *.spritefont, *.xnb, etc.) :** copier octets bruts
       - **Cas spécial `StarterGame.csproj` :** renommer le fichier de destination vers `{pascalName}.csproj`
       - **Cas spécial `nuget.config` :** après le string replace standard, écrire une version propre
         avec uniquement nuget.org (retirer la source `local-pokeforge` qui est un artefact de dev) :
         ```xml
         <?xml version="1.0" encoding="utf-8"?>
         <configuration>
           <packageSources>
             <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
           </packageSources>
         </configuration>
         ```
    5. Écrire message de succès : `Console.WriteLine($"Project '{name}' created. Run: cd {name} && dotnet run");`
    6. Return 0

    **Register(RootCommand root) :**
    ```csharp
    var cmd = new Command("new", "Scaffold a new PokeForge game project");
    var nameArg = new Argument<string>("name", "Project name (e.g. mon-jeu)");
    cmd.AddArgument(nameArg);
    cmd.SetHandler((name) => Environment.Exit(Execute(name)), nameArg);
    root.AddCommand(cmd);
    ```
    Éviter : utiliser `SetHandler` avec retour `int` directement (System.CommandLine beta4
    ne supporte pas `Func<int>` dans SetHandler — utiliser `Environment.Exit`).

    Éviter : string replace avec Regex (simple `string.Replace` suffit pour `StarterGame`).
    Éviter : récursion manuelle pour les dossiers (ZipArchive itère tous les entries plats).
  </action>
