    SDK.Tools est `OutputType=Exe` mais ses types publics dans leurs namespaces sont accessibles.
    EF Core et SixLabors.ImageSharp sont transitifs (pas de PrivateAssets=all sur ces packages dans SDK.Data/SDK.Tools).

    **Commands/AssetSyncCommand.cs** — créer :
    ```
    namespace PokeForge.Cli.Commands;
    using SDK.Tools.Validation; using SDK.Tools.Atlas; using SDK.Tools.Sync;
    using System.CommandLine; using System.Text.Json;
    ```
    Méthode `public static void Register(RootCommand root)` :
    - Command "asset-sync" avec description "Validate sprites, pack atlas, sync to SQLite"
    - Option `--config` `<string>` description "Path to import.json", defaultValueFactory `() => "assets/import.json"`
    - SetHandler : `(config) => Environment.Exit(Execute(config))`

    Méthode `internal static int Execute(string configPath)` :
    - Si `!File.Exists(configPath)` : `Console.Error.WriteLine($"import.json introuvable : {configPath}")` → return 1
    - `var config = JsonSerializer.Deserialize<ImportConfig>(File.ReadAllText(configPath))!`
    - Instancier `SpriteScanner scanner`, `SpriteValidator validator`
    - `IEnumerable<string> files` : try `scanner.Scan(config.SpritesRoot)` catch `DirectoryNotFoundException ex` → `Console.Error.WriteLine(ex.Message)` → return 1
    - `var results = validator.ValidateAll(files)` — copier le loop d'affichage de SDK.Tools/Program.cs (colors + messages)
    - `bool hasError = results.Any(r => r.Severity == SeverityLevel.Error)`
    - `var packable = results.Where(r => r.Severity != SeverityLevel.Error).Select(r => r.Entry.FilePath).ToList()`
    - Si `packable.Count > 0` : `AtlasPacker packer`, `var entries = packer.Pack(packable, config.OutputDir)`, `var atlasPath = Path.Combine(config.OutputDir, "atlas.png")`, `new SqliteSyncer(config.DbPath).Sync(entries, atlasPath)` → afficher résultats
    - Sinon : `Console.WriteLine("[WARN] Aucun sprite valide à packer.")`
    - return `hasError ? 1 : 0`

    **Program.cs** — ajouter `AssetSyncCommand.Register(rootCommand);` après la ligne NewCommand.

    Avoid : ne pas modifier SDK.Tools/Program.cs — la logique doit être dupliquée (SDK.Tools reste un outil standalone).
  </action>
