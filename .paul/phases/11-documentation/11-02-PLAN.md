<objective>
## Goal

Écrire le tutoriel 30min step-by-step (4 pages EN + 4 pages FR) qui guide un développeur de zéro à un fan-game fonctionnel avec combat + script Lua + badge, en 3 étapes progressives.

## Purpose

La page d'intro actuelle montre un "exemple en 30 secondes" — mais sans chemin complet. Le tutoriel comble ce manque : un nouveau contributeur suit les étapes et obtient un projet qui tourne, une bataille qui se résout, et un badge attribué via Lua — sans connaissance préalable du SDK.

## Output

- `docs/docs/tutorial/` — 4 fichiers EN (index + 3 steps)
- `docs/i18n/fr/.../tutorial/` — 4 fichiers FR miroirs
- `docs/sidebars.ts` — catégorie Tutorial insérée après 'intro'

    - Section "Prérequis" : .NET SDK 10+, SQLite, pokeforge CLI installé (`dotnet tool install -g PokeForge.CLI`), un terminal
    - Table des étapes avec liens : Étape 1 → Étape 2 → Étape 3

    **01-create.md** (sidebar_position: 2, titre "Étape 1: Créer un projet"):
    - Scaffolding : `pokeforge new MonJeu` — expliquer ce que la commande crée (dossiers, .csproj, Game1.cs)
    - Base de données : `cd MonJeu && pokeforge seed` — expliquer que seed remplit PokemonSDK.db avec 9 générations
    - Santé du projet : `pokeforge doctor` — output attendu (all green), que faire si un item est rouge
    - Démarrage headless : `dotnet run -- --headless` — output attendu, ne pas chercher de fenêtre graphique pour ce tutoriel
    - Callout "Tip" : pour lancer en mode graphique, omettre `--headless` (nécessite SDL2 + OpenGL)

    **02-battle.md** (sidebar_position: 3, titre "Étape 2: Premier combat"):
    - Ouvrir `src/Game1.cs`, localiser le bloc de démarrage
    - Ajouter le code C# : construire deux Pokémon (Bulbasaur vs Charmander via DbContext), créer BattleEngine + StandardDamageFormula + NormalDifficultyMode, appeler ExecuteTurn dans une boucle jusqu'à IsOver, logger le résultat
    - Code complet reproductible (copier-coller → fonctionne)
    - `dotnet run -- --headless` → output attendu dans la console : tours, winner
    - Bloc "Comprendre le code" : BattleState immuable (record + with), IDamageFormula pluggable, BattleConfig
    - Lien "Voir aussi" → packages/battle.md

    **03-lua-badge.md** (sidebar_position: 4, titre "Étape 3: Script Lua et badge"):
    - Créer `scripts/gym_first.lua` avec contenu : `game.give_badge("Badge Herbier")` + `game.set_flag("GYM1_DONE", true)` + `game.save()`
    - Modifier Game1.cs pour exécuter le script via LuaScriptEngine
    - Vérifier que save/load restaure le flag : ajouter log `Console.WriteLine(gameState.Flags["GYM1_DONE"])`
    - `dotnet run -- --headless` → output attendu : badge + flag loggés, fichier `saves/default.json` créé
    - Section "Et ensuite ?" avec liens : guides system (battle, lua, plugins), API reference (Phase 11-04)

    - Code blocks avec langage explicite (csharp, lua, bash)
