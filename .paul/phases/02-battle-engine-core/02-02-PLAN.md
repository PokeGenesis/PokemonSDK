<objective>
## Goal
Étendre SDK.Data pour couvrir les entités de combat : Migration 002 (tables Move/Ability/Learnset), configurations Fluent API, et BattleDataSeeder (tableau de types Gen 1 + moves Gen 1 + abilities).

## Purpose
Le battle engine (Plan 02-03) a besoin de données réelles en DB pour tourner : types de moves, catégories Physical/Special/Status, tableau d'efficacité des types (18×18 côté Gen 1 = 15 types non-neutres). Sans cette migration et ce seeder, SDK.Battle ne peut pas charger les données depuis SQLite.

## Output
- Migration 002 `AddBattleData` avec tables Move, Ability, Learnset
- 3 configurations Fluent API (MoveConfiguration, AbilityConfiguration, LearnsetConfiguration)
- `BattleDataSeeder` : 3 méthodes de seed (TypeEffectiveness, Moves, Abilities)
- `BattleDataSeederTests` : 4 tests validant les counts et structure
</objective>
