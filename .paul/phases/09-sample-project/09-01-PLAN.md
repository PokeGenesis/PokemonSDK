## Goal
Créer le meta-package `PokeForge.SDK` (8e package NuGet) qui agrège les 7 packages existants, permettant `dotnet add package PokeForge.SDK` pour tout installer en une commande.

Un développeur ne connaît pas forcément la décomposition interne Core/Data/Battle/Scripting/Plugins. Le meta-package offre un point d'entrée unique. Quand `PokeForge.SDK` v0.2.0 sort, tous les sous-packages se mettent à jour automatiquement — D-18 (SemVer strict) respecté globalement.

- `PokemonSDK.slnx` — SDK.Bundle ajouté dans le folder /src/

<task type="auto">
  <name>Task 1: Créer SDK.Bundle.csproj — meta-package PokeForge.SDK</name>
  <files>src/SDK.Bundle/SDK.Bundle.csproj</files>
  <action>
    Créer le dossier `src/SDK.Bundle/` et le fichier `SDK.Bundle.csproj` :

    ```xml
    <Project Sdk="Microsoft.NET.Sdk">
      <PropertyGroup>
        <TargetFramework>net10.0</TargetFramework>
        <PackageId>PokeForge.SDK</PackageId>
        <Version>0.1.0</Version>
        <Authors>PokeGenesis</Authors>
        <Description>PokeForge SDK — meta-package. Installe tous les modules PokeForge.SDK.* en une commande. Inclut Core, Data, Battle, Scripting et les plugins Nuzlocke/Randomizer/Turbo.</Description>
        <PackageTags>pokemon;fangame;sdk;monogame;battle-engine</PackageTags>
        <PackageLicenseExpression>MIT</PackageLicenseExpression>
        <RepositoryUrl>https://github.com/PokeGenesis/PokemonSDK</RepositoryUrl>
        <PackageProjectUrl>https://github.com/PokeGenesis/PokemonSDK</PackageProjectUrl>
        <Nullable>enable</Nullable>
        <ImplicitUsings>enable</ImplicitUsings>
        <!-- Metadata-only package : pas de code source, pas de fichiers DLL -->
        <IncludeBuildOutput>false</IncludeBuildOutput>
        <SuppressDependenciesWhenPacking>false</SuppressDependenciesWhenPacking>
        <NoWarn>NU5128</NoWarn>
      </PropertyGroup>

      <ItemGroup>
        <PackageReference Include="PokeForge.SDK.Core"              Version="$(Version)" />
        <PackageReference Include="PokeForge.SDK.Data"              Version="$(Version)" />
        <PackageReference Include="PokeForge.SDK.Battle"            Version="$(Version)" />
        <PackageReference Include="PokeForge.SDK.Scripting"         Version="$(Version)" />
        <PackageReference Include="PokeForge.SDK.Plugins.Nuzlocke"  Version="$(Version)" />
        <PackageReference Include="PokeForge.SDK.Plugins.Randomizer" Version="$(Version)" />
        <PackageReference Include="PokeForge.SDK.Plugins.Turbo"     Version="$(Version)" />
      </ItemGroup>
    </Project>
    ```

    Points critiques :
    - `IncludeBuildOutput>false` — meta-package sans DLL, uniquement les dépendances dans le .nuspec
    - `SuppressDependenciesWhenPacking>false` — assure que les 7 PackageReference apparaissent dans le .nuspec généré
    - `NoWarn>NU5128` — supprime le warning "no lib/ or ref/ content" attendu pour un meta-package
    - `$(Version)` dans les PackageReference — résolu au moment du `dotnet pack`, garantit cohérence de version
    - Ne pas ajouter `PrivateAssets="all"` sur les PackageReference — ces dépendances DOIVENT transiter vers les consumers
  </action>

  <done>AC-1 satisfait : PokeForge.SDK.0.1.0.nupkg créé avec 7 dépendances</done>
</task>
