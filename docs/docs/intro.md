# PokemonSDK

SDK open-source C# / .NET 10 pour fan-games Pokémon.

## Install

```bash
dotnet add package PokeForge.SDK.Core
dotnet add package PokeForge.SDK.Battle
dotnet add package PokeForge.SDK.Scripting
```

## Quick Start

See the [Packages overview](/docs/packages/) for available packages.

## Packages

| Package | Description |
|---------|-------------|
| PokeForge.SDK.Core | Entities, interfaces, value objects — zero NuGet dependencies |
| PokeForge.SDK.Data | EF Core 10 + SQLite, migrations, seeding |
| PokeForge.SDK.Battle | 1v1 headless battle engine |
| PokeForge.SDK.Scripting | MoonSharp Lua sandbox, GameState, SaveSystem |
| PokeForge.SDK.MonoGame | MonoGame DesktopGL runtime, HD render pipeline |
| PokeForge.SDK.Tools | Asset validation, atlas packing, Fakemon pipeline |
| PokeForge.SDK.Plugins | Nuzlocke, Randomizer, Turbo plugins |
| PokeForge.SDK.Plugins.TTS | Narration plugin (Piper TTS + Windows Speech) |
