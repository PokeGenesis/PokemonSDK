# Guides

Task-oriented guides for integrating each PokemonSDK subsystem into your fan game. The Tutorial covers the 30-minute path from zero to a running game. These guides go deeper on each feature area.

| Guide | Description |
|-------|-------------|
| [BattleEngine: Wire 1v1 Combat](guides/battle-engine) | Configure formulas, run a battle loop, integrate with MonoGame |
| [Lua Scripting: NPC Events and Badges](guides/lua-scripting) | Write scripts, give badges, persist save state |
| [Plugins: Extend the Battle Engine](guides/plugins) | Implement IBattlePlugin, use Nuzlocke/Randomizer/Turbo |
| [Asset Pipeline: Sprites and Atlases](guides/asset-pipeline) | Name sprites, generate atlases, sync to SQLite |
| [HD Rendering: 480x270 to 1080p](guides/rendering-hd) | Set up RenderPipeline, 3-pass Draw, day/night tint |
| [TTS Narration: Voice Dialogue](guides/tts-narration) | Register PiperNarrationPlugin, call from Lua |
| [Fakemons: Custom Species](guides/fakemons) | Assemble sprites, export to SQLite with 6-locale translations |
