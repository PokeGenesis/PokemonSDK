# Guides

Guides orientés tâches pour intégrer chaque sous-système de PokemonSDK dans votre fan game. Le Tutoriel couvre le parcours de 30 minutes, de zéro à un jeu fonctionnel. Ces guides vont plus loin sur chaque domaine fonctionnel.

| Guide | Description |
|-------|-------------|
| [BattleEngine : combat 1v1](guides/battle-engine) | Configurer les formules, lancer une boucle de combat, intégrer avec MonoGame |
| [Scripting Lua : événements NPC et badges](guides/lua-scripting) | Écrire des scripts, donner des badges, persister l'état de sauvegarde |
| [Plugins : étendre le moteur de combat](guides/plugins) | Implémenter IBattlePlugin, utiliser Nuzlocke/Randomizer/Turbo |
| [Pipeline d'assets : sprites et atlas](guides/asset-pipeline) | Nommer les sprites, générer des atlas, synchroniser avec SQLite |
| [Rendu HD : 480x270 vers 1080p](guides/rendering-hd) | Configurer RenderPipeline, Draw en 3 passes, teinte jour/nuit |
| [Narration TTS : dialogue vocal](guides/tts-narration) | Enregistrer PiperNarrationPlugin, appeler depuis Lua |
| [Fakemons : espèces personnalisées](guides/fakemons) | Assembler des sprites, exporter vers SQLite avec 6 locales |
